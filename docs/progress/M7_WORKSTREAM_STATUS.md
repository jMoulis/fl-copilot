# M7 — suivi des sept chantiers V1

Mis à jour le 18 octobre 2026. Ce suivi reprend les sept chantiers convenus avec Julien. Leur périmètre reste stable ; les améliorations hors critère de sortie vont dans la roadmap suivante. Chaque PR doit préciser le chantier concerné, le résultat concret, le reste à faire et l’état de livraison. Le nombre de PR et les pourcentages ne sont pas des preuves d’avancement.

**Vocabulaire :** « à démarrer », « en cours », « code prêt », « livré », « validé ». Un code fusionné et testé reste « code prêt » tant qu’il n’est pas livré. La validation utilisateur sur iPhone est distincte des tests automatisés. Un chantier entier ne devient « code prêt » que lorsque son critère de sortie est couvert.

## Ordre de poursuite

Terminer les manques du chantier 1 par lots métier complets et tenir cet inventaire à jour ; préparer ensuite la livraison/acceptation groupée adaptée. Ne pas multiplier les PR de simples couches internes présentées comme des fonctionnalités utilisables. Les sept critères de sortie restent la référence commune jusqu’à clôture M7 ; M8 conserve ses exigences de mise en production.
