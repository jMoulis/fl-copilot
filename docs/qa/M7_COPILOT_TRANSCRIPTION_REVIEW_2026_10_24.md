# M7 — source-scoped commercial transcription comparison in chat, 24 October 2026

## Scope and preserved policy

An exact opt-in `x-copilot-transcription-review: 1` exposes `commercial_transcription_review` for an explicit request concerning one known PDF source. Its only model argument is `sourceDocumentId`. The server verifies confirmed same-store document metadata and returns `REVIEW_LOCAL`, without claiming a local conflict count or executing a resolution. Unknown/combined capability values stay disabled; existing tool versions, five-read budget and three-source-card limit are preserved. No global prompt, model/provider change, migration or new conflict writer is introduced.

The device discovers its own current source-bound captures in pages of ten and opens one comparison at a time. Full source/checksum, occurrence, current group, device commands and private artifact authority are checked through the existing canonical review. The first accepted transcription is immutable: the only offered resolution is explicit adoption after comparison. Rejected local packets remain FAILED/SUPERSEDED, never falsely ACKNOWLEDGED. Local corrections, source rows/pages and history remain retained; this is not offer retention, commercial validation, publication, planning or execution.

`CommercialReviewRepository.useRemoteDecision` remains the writer. It joins the existing reviewed-operation transaction, with native current-context/abort/hash checks. Its canonical capture and private result commit together; failure rolls both back. A stable per-card/per-capture operation UUID supports separate source occurrences and exact retry/reopen. A committed result does not depend on a later read succeeding. Recorded comparisons remain accessible from the source card. The shared manual presentation is reused, with a single original-document link in chat.

Two mounted-card counterexamples exposed a shared lifetime defect: a retained checkbox callback could mark a different document, or a freshly re-read comparison, as already compared. The common hook now checks committed scope/focus/revision/read state before accepting that checkbox update. The same correction protects the manual transcription page and other users of that hook, without adding a business rule or another lifetime implementation. A separate real-hook render witness reproduced the previous context’s data being rendered while the new context read was pending; the stored review is now tagged with its committed scope. A cancellation injected during private-journal insertion also reproduced a commit after cancellation; the existing shared transaction rechecks cancellation after that final insert, and the source controller checks its current lifetime before returning its transaction.
