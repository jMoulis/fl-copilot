## Coherent scope

The opt-in `x-copilot-visual-actions: 1` capability exposes `product_visual_preview` for an explicit existing-library assignment, removal of one product association, or global withdrawal of the currently resolved asset. The model never writes metadata, chooses actors/permissions, downloads a binary, grants rights or generates an image. The existing five-read/turn, evidence and three-proposal bounds remain unchanged. An optional literal name query makes the existing identity-library reader usable without scanning arbitrary UUID pages; old absent-query requests retain their shape.

A compact proposal binds the full canonical product snapshot and visual metadata hashes, including provenance that is not sent to the model. Server reads and native review share the projection and canonical selected-image policy. The immutable TOOL record is stored through the existing turn transaction and synchronized private history. Unknown/combined capability values stay disabled; earlier conflict capabilities keep their contracts.

The native card delegates to `assignLibraryVisual`, `removeProductVisual` or `revokeLibraryVisual` inside the existing reviewed-operation transaction. Canonical eligibility and record-writability checks are extracted from those same writers, not copied into another mutation policy. Current scope, group/hash, cancellation and exact private artifact authority are checked again before commit. Metadata, Outbox, transfer jobs and private result roll back together. A committed result does not depend on a subsequent read succeeding. Replay after restart creates no second command.

Assignment requires a successfully opened/decoded local preview plus explicit human comparison. A decode failure removes that approval. Restoring a retired association and withdrawing an image for every linked product require independent native consents. Scope, focus, reread and role changes invalidate approval and retained callbacks. Existing preview recovery is explicit and uses normal file synchronization; no automatic model call, image sourcing or generation is introduced. Global withdrawal retains originals and only cancels transfer work for that asset.
