## Change

Extend the existing canonical-chat immediate catalogue with `store_week`,
`store_events` and `substitution_lookup`, only when their authorized reader is
configured. Keep SDK discovery for specialized capabilities and all existing
review/confirmation boundaries. No new tool, model, agent, router, prompt rule,
read quota, source/result projection or data mutation.

Replace the existing Journal description with a shorter description matching
the daily archive: production AI turns do not refresh public providers. Preserve
source freshness/gaps, monthly national economy qualification, untrusted-source
handling and the absence of a causal conclusion.

The initial tool definitions cost more upfront when present. The intended gain
is fewer repeated discovery steps and less prefix churn on mixed analytical
questions. Actual savings require a real owner retest; controlled transports do
not prove model selection, cache hits or billed savings.
